# Smart Public Service Jakarta - Resilience Dashboard v2.0

Dashboard intelijen ketahanan perkotaan dan kesehatan berbasis **Next.js 14**, **Leaflet**, **Recharts**, dan **Open Data DKI Jakarta**.

## 🚀 Fitur Baru v2.0:
- **Grafik Tren & Perbandingan (Recharts):** Analytics tren ISPU harian vs ISPA dan perbandingan BOR/ISPU antar wilayah.
- **Matriks Risiko Lingkungan & Kesehatan:** Tabel detail parameter indikator risiko kota.
- **Tabel Status Stasiun Pantau:** Pemantauan real-time stasiun DLH & Pos Pantau SDA Jakarta.
- **Policy Recommendation Panel:** Rekomendasi tindakan kebijakan otomatis.

## 📦 Jalankan & Deploy
1. Ekstrak file dan jalankan `npm install`
2. Jalankan lokal: `npm run dev`
3. Push ke GitHub dan pastikan Root Directory Vercel sesuai.
